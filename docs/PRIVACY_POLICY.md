### 1. Zero Cloud Data Collection
DisplayMac operates exclusively over your local Wi-Fi / direct USB link. We do **not** collect, store, transmit, or sell any personal data, keystrokes, screen recordings, or device identifiers to any cloud server or third party.

### 2. Local Network Communication
When connecting devices via a 6-digit PIN, communication occurs strictly through peer-to-peer UDP broadcast and direct TCP connections on your local network. Your screen video and control inputs never leave your local private network.

### 3. Permissions Used
- **Screen Recording (macOS & Android):** Used strictly to capture the screen or window that you explicitly choose to stream to your peer device.
- **Accessibility Service (macOS & Android):** Used exclusively to translate remote mouse/touch clicks into local cursor taps and gestures when remote control is active.
- **Local Network / Wi-Fi Multicast:** Used to discover devices using the 6-digit code on the same Wi-Fi network.

### 4. Updates & Feedback
Checking for updates requests public version information from GitHub. When you submit feedback via the app, your email client opens a pre-composed email directly to `sumitranjanhisu@gmail.com`.
